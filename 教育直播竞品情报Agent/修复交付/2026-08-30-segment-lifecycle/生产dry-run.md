## 判定口径

- canonical 只来自 `media-manifest.json` 内明确的 `final_path`。实际重算 manifest SHA-256，并与数据库 `manifest_hash` 比较。
- final_path 必须存在，实际字节数同时匹配 manifest、`media_manifests.total_bytes` 和 exact-path segment；manifest 声明的 final SHA-256 必须匹配该 segment checksum。
- 本次为降低对正在录制磁盘的影响，没有重算每个大型 final media 的全文件 SHA-256；该边界已在 JSON 中明确标注。
- 不使用文件名推断 canonical。没有通过上述验证的 canonical 时，缺失 segment 一律进入人工复核，绝不建议自动 supersede。
- WAITING_TOOL 只有在 source_path 缺失、segment 引用存在、source_digest/path 完全一致、canonical 已验证、output 不存在且失败原因匹配时，才建议安全取消。
