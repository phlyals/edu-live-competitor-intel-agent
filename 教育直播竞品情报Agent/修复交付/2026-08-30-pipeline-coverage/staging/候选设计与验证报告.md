# Pipeline FULL_SESSION 时间戳覆盖率门禁：隔离候选报告

## 边界

本次只在 `staging/` 内制作候选，没有修改生产文件、PostgreSQL、媒体、业务服务或 Analysis。生产 `v3_pipeline_worker.py` 和 `v3_config.json` 的 SHA-256 仍与开始时一致。

## 候选行为

1. `segments` 必须为非空数组；每个片段必须是对象，`start/end` 必须是有限数值，且满足 `0 <= start < end <= 实际音频时长`。任意一条非法即 fail-closed，不会丢弃坏片段后假装合格。
2. 按时间区间并集计算 `covered_segments`、`gaps`、`covered_duration_seconds` 和 `coverage_rate`；同时保留未去重的 `raw_covered_duration_seconds/raw_coverage_rate`，便于发现重叠片段。
3. `FULL_SESSION` 只有在时间戳全部合法且并集覆盖率 `>= 0.90` 时才能写为 `COMPLETE`。否则写为 `QUALITY_BLOCKED`，不会生成音频 retention job，也不会进入当前只读 `COMPLETE` 的下游。
4. `0.95` 是生产目标，但不是硬门槛。元数据同时报告 `minimum_coverage_rate=0.90`、`target_coverage_rate=0.95` 和 `meets_target`。
5. 已有 `COMPLETE` 但没有 `timestamp_coverage` 的同一 `source_digest` 不再跳过。如果旧音频和输出仍存在，直接复用不可变 artifact 重验证，不重跑 ASR。
6. Pipeline heartbeat 报告 `full_session_qualified`、`full_session_meets_target`、`quality_blocked`、`eligible_canonical_pending` 以及缺失 source/output/unrecoverable 积压。存在质量阻断、不可恢复积压或 eligible canonical 待转录时心跳为 `DEGRADED`。
7. `CANCELLED_SUPERSEDED_SOURCE` 是已解决的生命周期墓碑，不计入 stale 积压。
8. qualified、meets-target 和 quality-blocked 只认当前 `CANONICAL_ACTIVE` 整场媒体对应的 `source_digest = sha256("FULL_SESSION:" + recording_segments.checksum)`。缺少 checksum 时只对存在的当前媒体安全重算。历史 quality 行保留可查，但不污染当前心跳；所有统计按 session 去重。
9. 同一 `source_digest` 已按相同 schema=1、硬门槛和 target 得出 `QUALITY_BLOCKED` 且 artifact 仍存在时，后续30秒轮询直接幂等跳过，不重跑 ASR、不重算、不重写文件。门槛、target 或 schema 变化后会重验证。

## 已知 trade-off

1. 时间戳并集测量的是“有转录片段的音频时间”，无法区分真实静音、音乐、VAD主动略过和实际漏转。长静音直播可能被 90% 门槛误拦；本候选按要求 fail-closed，没有自行放宽。
2. 任何一个非法时间戳都会使整份转录进入 `QUALITY_BLOCKED`，这可能增加人工复核，但避免将有问题的数据当成整场。
3. 部署后，旧 `COMPLETE` 整场记录在首次重验证时可能被降为 `QUALITY_BLOCKED`。已经生成的 Analysis 记录不在本项范围内，本候选不删除、改绑或重算它们。
4. eligible canonical 在 ASR 执行完前会让 Pipeline 显示 `DEGRADED`，能防止“有待办却报 READY”，但会增加告警时长。
5. 心跳使用本地文件存在性检查。历史 URL 或只存在外部系统的 artifact 会显示为 missing，需在部署前通过只读预检查确认告警规模。

## 部署前仍需要的证据

本轮只证明候选逻辑与回归通过，不代表生产已修复。正式部署前应用显式 READ ONLY 查询预演当前所有 transcript 的新状态和 heartbeat 计数，特别是旧 `COMPLETE` 会降级的数量；部署时只重载 Pipeline，然后观察一份真实 `FULL_SESSION` artifact 通过 90% 硬门槛。
