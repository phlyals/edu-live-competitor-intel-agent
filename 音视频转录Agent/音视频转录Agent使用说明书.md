# 音视频转录 Agent 使用说明书

- 版本：V0.2
- 更新日期：2026-08-25
- 使用入口：飞书 Bot「音视频转录 Agent」
- 当前范围：单个抖音直播间、指定时长录制、转录、清洗和单场分析

## 它是什么

这是一个单场直播研究助手：你在飞书中给它一个当前正在直播的抖音直播间链接，它会先检查环境并等待确认，然后自动完成录制、音频提取、中文逐字稿、保守清洗和本场直播内容分析。

它不是长期直播监控系统，也不会自动寻找同行。

## 省了什么人工

- 之前：人工检查直播、启动录屏或下载工具、等待录制、用 FFmpeg 提取音频、运行 Whisper、整理时间戳、清洗逐字稿、阅读全文并写分析。处理一个20分钟直播样本，通常需要约60～120分钟人工操作和整理。
- 现在：用户只需在飞书发送直播链接和时长，预检通过后回复一次“继续”。后续录制、转录、清洗、分析、保存和进度通知由 Agent 完成。
- 量化：人工投入约60～120分钟 → 约1～3分钟。机器总耗时仍包括直播录制时长和模型处理时间；20分钟样本通常需要约30～60分钟自然等待，具体取决于网络、电脑性能和分析模型速度。

这里节省的是人工占用时间，不是把20分钟直播瞬间处理完成。

## 用了什么工具

- Codex：负责搭建、修改、排查和自检 Agent 的本地代码与运行环境。Codex不是每次直播任务必须调用的业务入口。
- Hermes：负责接收飞书消息、识别用户意图、加载独立 Profile、调用任务 Runtime、维护飞书 Bot 会话。
- Profile-local Runtime：负责任务ID、状态、任务锁、Checkpoint、Heartbeat、文件登记、断点恢复和飞书 Outbox。
- DouyinLiveRecorder：负责解析抖音直播间状态和直播流；Agent不自行实现抖音流解析。
- FFmpeg / FFprobe：负责保存直播录像、提取16kHz单声道WAV音频，并验证媒体时长。
- Whisper / faster-whisper：负责本地中文语音识别、时间戳和低置信度片段标记。
- DeepSeek 官方模型：负责根据本场真实逐字稿生成单场直播分析。
- 飞书 CLI：当前业务主链不直接依赖 `lark-cli`。飞书消息由 Hermes Gateway 和 `hermes send` 通道收发；`lark-cli`只在需要人工检查飞书资源或排查权限时使用。

## 输入

- 输入1：当前正在直播的抖音直播间链接。
  - 格式：完整HTTPS链接，例如 `https://live.douyin.com/123456789`。
  - 来源：抖音直播间分享链接、浏览器地址栏或抖音分享文本中的链接。
  - 支持：`live.douyin.com`、`v.douyin.com`等抖音域名。
- 输入2：希望录制的时长。
  - 格式：自然语言，例如“录制1分钟”“录制20分钟”。
  - 可选：不填写时默认20分钟。
- 输入3：确认指令。
  - 格式：预检通过后，单独回复“继续”。
  - 作用：只有收到明确确认，Agent才会开始长任务。

## 如何触发

### 第一步：在飞书找到 Bot

打开飞书，搜索并进入「音视频转录 Agent」私聊。

如果陌生人搜索不到，需要管理员先把该用户加入飞书应用的可用范围。

### 第二步：发送链接和录制时长

推荐格式：

```text
请录制这个抖音直播间20分钟，并做单场直播分析：
https://live.douyin.com/真实直播间ID
```

第一次测试建议使用：

```text
请录制这个抖音直播间1分钟，并做单场直播分析：
https://live.douyin.com/真实直播间ID
```

### 第三步：等待预检结果

Agent会检查：

- 链接是否属于抖音；
- 当前是否正在直播；
- 录制器、FFmpeg、Whisper和本地模型是否可用；
- 输出目录是否可写、磁盘空间是否足够；
- 分析模型是否可用；
- 飞书 Gateway 是否真实在线。

直播状态分为：

- `LIVE`：明确正在直播，可以等待确认；
- `OFFLINE_CONFIRMED`：明确未开播，任务停止；
- `UNKNOWN`：网络、解析、风控或工具异常，不能把它当成未开播。

### 第四步：回复“继续”

预检通过后，Agent会给出任务ID、主播、录制时长和预期文件。确认无误后回复：

```text
继续
```

Agent会重新检查直播状态，并在后台开始任务。重复发送“继续”不会重复录制同一个任务。

### 第五步：查看进度

飞书中会陆续收到：

```text
开始录制
录制完成
开始提取音频
开始本地转录
转录完成
清洗完成
开始单场分析
任务完成或部分成功
```

如果需要查询任务，可以发送：

```text
查询任务 AV-20260825-153012-A7F3
```

如果任务因工具或网络问题中断，可以发送：

```text
恢复任务 AV-20260825-153012-A7F3
```

恢复时会复用已经验收通过的录像、音频和逐字稿，不会从头重复录制。

## 输出示例

每个任务会建立独立目录：

```text
直播竞品研究/
  AV-日期-时间-随机ID_主播名/
    00_任务元数据.json
    00_直播录像.ts
    01_直播音频.wav
    02_逐字稿_带时间戳.md
    03_逐字稿_清洗版.md
    04_竞品直播分析.md
```

其中：

- `00_任务元数据.json`：任务状态、Checkpoint、错误、录制时长和文件登记；
- `00_直播录像.ts`：原始直播录像，后续步骤失败也不会删除；
- `01_直播音频.wav`：16kHz、单声道、PCM音频；
- `02_逐字稿_带时间戳.md`：原始中文逐字稿，可按时间回看录像；
- `03_逐字稿_清洗版.md`：保留原意和时间戳的保守清洗稿；
- `04_竞品直播分析.md`：只分析这一场直播，不做跨场比较和话术迁移。

## 圈友怎么用

### 只使用现成 Agent

1. 联系管理员，把你的飞书账号加入「音视频转录 Agent」应用可用范围。
2. 在飞书搜索「音视频转录 Agent」，进入私聊。
3. 找到一个当前正在直播的抖音直播间。
4. 发送“请录制这个直播间1分钟并做单场分析”加直播链接。
5. 查看预检结果。必须看到 `LIVE` 才能继续。
6. 回复“继续”。
7. 等待飞书阶段进度，不需要保持聊天窗口打开。
8. 收到最终消息后，优先查看带时间戳逐字稿、清洗稿和单场分析。
9. 如果出现失败，按消息中的任务ID发送“恢复任务 + 任务ID”。

### 在另一台Mac复刻

需要准备：

- Hermes及独立Profile；
- 飞书应用和Bot；
- Python运行环境；
- FFmpeg和FFprobe；
- DouyinLiveRecorder；
- 本地Whisper或faster-whisper模型；
- 一个可用的分析模型API；
- 至少10GB可用磁盘空间。

关键目录：

```text
~/.hermes/profiles/yinshipinzhuanluagent/
  SOUL.md
  skills/douyin-live-competitor-research/SKILL.md
  runtime/
```

初始化和自检：

```bash
/Users/mac/AI/apps/hermes/tools/avtranscribe/.venv/bin/python \
  ~/.hermes/profiles/yinshipinzhuanluagent/runtime/taskctl.py init

/Users/mac/AI/apps/hermes/tools/avtranscribe/.venv/bin/python \
  ~/.hermes/profiles/yinshipinzhuanluagent/runtime/taskctl.py self-check
```

只有自检返回 `READY`，并确认飞书 Gateway 真实在线后，才能提交直播任务。

## 注意事项

### 什么事情它做不了

- 不能根据商品链接自动寻找同行；
- 不能长期监控多个主播；
- 不能同时批量录制多个直播间；
- 不比较同一个主播的前后两场直播；
- 不维护话术打法版本；
- 不建立策略候选库；
- 不生成话术迁移或原创直播话术；
- 不自动修改正式知识库；
- 不自动删除历史录像、音频或逐字稿；
- 不读取真实销量、成交人数或转化率；
- 不保证绕过抖音登录、验证码、风控或平台限制。

### 什么情况需要人工介入

- 抖音链接无效、直播已结束或状态为 `UNKNOWN`；
- 抖音出现登录、验证码、风控或访问限制；
- 磁盘空间不足或外接存储未挂载；
- 录制异常，只得到部分录像；
- Whisper无法识别关键内容或低置信度片段较多；
- 分析报告未通过自动验收，状态为 `ANALYSIS_REVIEW_REQUIRED`；
- 飞书Bot不在用户可用范围；
- Gateway进程退出或飞书连接断开；
- 用户需要判断主播案例、政策或效果数据是否真实。

### 已知问题和后续改进方向

- 当前新版本已完成工程自检、合成媒体测试、真实逐字稿分析和飞书真实回发，但仍建议用一个正在直播的链接完成1～2分钟正式端到端验收。
- 本地Whisper识别质量会受到主播口音、背景音乐、连麦、网络丢帧和直播音质影响。
- 长直播的转录和分析耗时取决于Mac性能和模型接口速度。
- 飞书默认返回文件位置；大体积录像和WAV不建议直接上传飞书。
- 任务使用本地绝对路径，其他电脑无法直接打开这些文件；如需多人协作，后续可增加受控云盘上传。
- 当前没有飞书界面成功截图，正式对外分享前应补充一次真实短录截图。

### 合规提醒

- 只录制你有权访问和研究的直播内容；
- 遵守抖音平台规则、版权、隐私和当地法律；
- 不得把同行原话直接用于抄袭或洗稿；
- Agent分析属于内容研究，不代表销量或转化效果已被验证。
